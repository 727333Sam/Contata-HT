Layer Architecture Details

🌐 Frontend Layer

  • React 18 with TypeScript strict mode
  • React Beautiful DnD — Kanban 4-column drag & drop
  • React Flow — Interactive DAG visualization
  • Axios — HTTP client with interceptors
  • Zustand — Lightweight state management
  • Optimistic UI — Instant drag feedback + backend validation
  • 4 Columns: Backlog | In Progress | Review | Done

⚙️ Backend Layer

  • FastAPI — Async REST API with auto-docs
  • DAG Engine — Cycle detection, schedule propagation
  • Schedule Propagator — Kahn's algorithm + BFS with visited-set
  • AI Suggester — Claude API integration, confidence thresholding
  • Pydantic — Type-safe request/response validation
  • Alembic — Database migrations
  • Rate limiting on AI suggestion endpoints

🗄️ Database Layer

  • PostgreSQL — Relational database with JSONB support
  • SQLAlchemy ORM — Type-safe ORM, parameterized queries
  • Tasks Table — UUID, title, description, status, dates, position
  • Dependencies Table — Source/target FKs, suggested_by, validated
  • Unique constraint on (source, target) pairs
  • Transaction-wrapped all dependency mutations
  • Row-level locking on concurrent dependency operations

🤖 AI Integration Layer

  • Claude API (claude-sonnet) — Dependency suggestion
  • Structured prompting — JSON output format
  • Confidence thresholding — Only >0.6 shown to user
  • Human-in-loop — Accept/Reject in Suggested Dependencies panel
  • Backend validation — All returned IDs verified against DB
  • Graceful degradation — LLM down? All features still work

Core Algorithms

🔄 Cycle Detection

DFS with white/gray/black coloring scheme. O(V+E) per edge addition. Rejects circular dependencies in real time. Graph remains unchanged on rejection.

📈 Schedule Propagation

Topological sort (Kahn's) + BFS with visited-set. Each downstream task: start_date = max(end_dates of all predecessors). No compounding on converging paths.

⏪ Rollback on Regression

Moving completed task back to In Progress re-blocks all downstream dependents. Blocked = any unsatisfied prerequisite. Recalculated dynamically on every upstream change.
